# Fenora

Fenora — это современный десктопный музыкальный плеер, созданный на базе Electron. Fenora является идейным наследником плеера **mbox**, предлагая улучшенный визуал, расширенный функционал и высокую производительность.

## 🚀 Ключевые особенности (Features)

* **Агрегация музыки:** Возможность поиска и агрегации треков из Яндекс Музыки и SoundCloud прямо в приложении.
* **Эко-режим (Eco-mode):** Специальный режим для слабых ПК, который отключает тяжелые визуальные эффекты и сильно оптимизирует работу плеера без потери качества звука.
* **Глубокая кастомизация:** Настройка интерфейса под себя. Поддержка загрузки GIF-фонов, смены шрифтов, настройки интенсивности анимаций и выбора режимов акцентных цветов.
* **Улучшенный поиск текста:** Интеграция с базой LRCLIB для точного поиска синхронизированных текстов песен.
* **Современный UI/UX:** Переработанная панель навигации (боковая панель) и выезжающая панель библиотеки.

## ❓ Частые вопросы (FAQ)

**Вопрос: Что такое Fenora?**
Ответ: Fenora — это легкий и настраиваемый музыкальный плеер для Windows/Mac/Linux на базе Electron, являющийся наследником плеера mbox.

**Вопрос: Какие технологии используются?**
Ответ: Приложение работает на Electron. В разработке используются библиотеки `yamd2` (Яндекс Музыка), `soundcloud.ts` (SoundCloud), `ffmpeg-static` и `LRCLIB` для поиска текста песен.

**Вопрос: Будет ли Fenora работать на слабом компьютере?**
Ответ: Да, благодаря встроенному «Эко-режиму», который отключает тяжелые визуальные эффекты, плеер будет работать плавно даже на слабых ПК.
